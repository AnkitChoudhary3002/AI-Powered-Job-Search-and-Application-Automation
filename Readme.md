# AI Job Search Assistant

A Python-based job discovery and application-support system. It searches
for relevant vacancies through Google Search (Serper), enriches and
validates listings, matches them against a candidate profile using
OpenRouter, and keeps a record of applications.

Applications are **not submitted automatically**. The candidate reviews
each opportunity and completes the application manually.

## Directory and file responsibilities

### `candidate/`

  -----------------------------------------------------------------------
  File                                Responsibility
  ----------------------------------- -----------------------------------
  `candidate_profile.yaml`            Stores the candidate's education,
                                      skills, experience, projects, job
                                      preferences, and locally retained
                                      contact information.

  -----------------------------------------------------------------------

Keep API keys and other secrets out of this file. Contact information
should remain local and must not be included in prompts sent to the
language model.

### `agents/`

  -----------------------------------------------------------------------
  File                                Responsibility
  ----------------------------------- -----------------------------------
  `candidate_profiler.py`             Reads the candidate profile and
                                      creates a structured candidate
                                      summary.

  `job_discovery.py`                  Searches Google through Serper and
                                      stores discovered job listings.

  `job_enrichment.py`                 Visits listing URLs where
                                      accessible and attempts to extract
                                      employer and job-description
                                      details.

  `job_validator.py`                  Applies basic URL, metadata, and
                                      job-title checks; separates valid,
                                      rejected, and manual-review
                                      listings.

  `application_agent.py`              Compares jobs with the candidate
                                      summary, calculates a fit score,
                                      prepares application material, and
                                      asks for manual approval.

  `application_tracker.py`            Checks the company cooldown and
                                      records applications confirmed by
                                      the candidate.
  -----------------------------------------------------------------------

### `outputs/`

  -------------------------------------------------------------------------------
  File                         Generated by               Purpose
  ---------------------------- -------------------------- -----------------------
  `candidate_summary.json`     `candidate_profiler.py`    Structured candidate
                                                          information used for
                                                          matching.

  `jobs.json`                  `job_discovery.py`         Raw search results.

  `enriched_jobs.json`         `job_enrichment.py`        Search results
                                                          supplemented with
                                                          extracted details.

  `validated_jobs.json`        `job_validator.py`         Listings with
                                                          validation status and
                                                          reason.

  `application_queue.json`     `application_agent.py`     Jobs selected for
                                                          review, with fit
                                                          information and
                                                          prepared application
                                                          content.

  `application_history.json`   `application_tracker.py`   Submitted-application
                                                          records used for the
                                                          7-day company cooldown.
  -------------------------------------------------------------------------------

### Root-level files

  -----------------------------------------------------------------------
  File                                Responsibility
  ----------------------------------- -----------------------------------
  `run_workflow.py`                   Runs the complete workflow in
                                      sequence: profiling, job discovery,
                                      enrichment, validation, and
                                      application preparation.

  `.env`                              Holds API credentials and
                                      configuration such as the
                                      OpenRouter model. Do not commit
                                      this file or share its contents.

  `test_openai.py`                    Tests connectivity to the
                                      configured OpenRouter-compatible
                                      API.

  `test_jobs_api.py`                  Tests the job-search API
                                      integration.
  -----------------------------------------------------------------------

## Run order

Run the complete workflow with one command from the project root:

``` powershell
python run_workflow.py
```

The workflow runner executes these scripts in order:

``` text
agents/candidate_profiler.py
agents/job_discovery.py
agents/job_enrichment.py
agents/job_validator.py
agents/application_agent.py
```

The scripts can also be run individually:

``` powershell
python agents/candidate_profiler.py
python agents/job_discovery.py
python agents/job_enrichment.py
python agents/job_validator.py
python agents/application_agent.py
```

`application_tracker.py` is imported by the application workflow; it is
not normally run as a standalone step.

**Integration note:** The application agent reads
`outputs/validated_jobs.json` and evaluates only jobs with
`validation_status` set to `valid`.

## Important behavior and limitations

-   The Google Search recency filter is a discovery aid; it does not
    prove the employer posted a vacancy within the last 24 hours.
-   Enrichment depends on the target website being accessible and
    exposing useful page metadata. Extraction can be incomplete or
    incorrect.
-   Basic validation rules are heuristics. A listing marked `valid` is
    not proof that the vacancy is active, legitimate, or suitable.
-   Seniority filtering based on title keywords can miss senior roles
    with unusual titles and can occasionally reject a role whose title
    contains a matching word.
-   Fit scores and generated cover letters should be reviewed for
    accuracy.
-   The candidate retains control of every application. The system
    records an application only after the candidate confirms successful
    submission.
-   The 7-day cooldown is based on the employer name stored in
    application history. Use the actual hiring company name rather than
    the job-board name.

## Local setup

1.  Create and activate the project's Python virtual environment.
2.  Install the dependencies used by the scripts (for example,
    `requests`, `python-dotenv`, `openai`, `PyYAML`, and
    `beautifulsoup4`).
3.  Add `SERPER_API_KEY` and `OPENROUTER_API_KEY` to `.env`.
4.  Run the scripts from the project root so their relative project
    paths resolve consistently.

Never commit `.env`, API keys, or private candidate contact details to a
public repository.
